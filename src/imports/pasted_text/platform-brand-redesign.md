Improve this PlatformBrand / QuickShotTransfer website design from a strong V1 foundation to a more senior, premium launch-ready design.

Use the current design as the base. Do not restart from scratch unless necessary. Keep the overall page structure, but improve the visual polish, hierarchy, brand credibility, product mockups, and conversion quality.

Context:
PlatformBrand is a placeholder parent brand for a future family of cross-device utilities.
QuickShotTransfer is the first product.

QuickShotTransfer positioning:
“An instant visual capture inbox for iPhone-to-PC workflows. Send screenshots, photos, and visual references from your phone to your desktop in seconds.”

Core homepage message:
“Stop emailing yourself screenshots.”

Design goal:
Make the site feel like a serious, polished software company launching a paid desktop utility — not a generic Tailwind SaaS template and not a hobby project.

Keep:
- Homepage
- Product page
- Pricing page
- Download page
- Support / FAQ page
- Privacy / Terms placeholders
- Header and footer
- Free and Pro pricing
- QuickShotTransfer as the main/first product

Do not add:
- fake testimonials
- fake user counts
- fake company logos
- native iPhone app promises
- Mac app promises
- OCR/search as active features
- multiple fake products as if they already exist

Main improvements needed:

1. Make the hero more premium and product-led
Keep the headline:
“Stop emailing yourself screenshots.”

Keep/support this subheadline:
“Send screenshots, photos, and visual references from iPhone to PC in seconds.”

Improve the hero visual so it feels like a real product moment:
- polished desktop app mockup
- phone upload screen mockup
- visual flow from phone → QuickShot Cloud → Windows PC
- small “Sent to PC” success state
- floating image thumbnails moving toward the desktop app
- subtle depth, shadows, glow, or gradient background
- not too cartoonish

The hero should instantly explain what the product does without needing lots of text.

2. Replace generic placeholder mockups with more realistic product visuals
Use high-fidelity UI mockups that look close to the actual app:
- desktop app with sidebar
- latest image preview
- recent transfers grid
- search bar
- quick action buttons
- phone upload page with “Send Images to PC”

Avoid plain gray placeholder boxes. The mockups should feel credible enough for a paid product website.

3. Strengthen the brand identity
Even though “PlatformBrand” is temporary, make the brand area feel real:
- create a simple abstract logo/icon mark
- make a professional wordmark layout
- use a consistent brand style across header/footer/cards
- avoid the feeling of plain text placeholder branding

The logo can be generic enough to replace later, but it should make the site feel finished.

4. Refine the visual palette
The current blue SaaS palette is clean but slightly generic. Make it more premium:
- deep navy / graphite text
- off-white or soft neutral backgrounds
- refined blue/cyan/indigo accent
- subtle gradients
- less default bright blue everywhere
- stronger contrast on CTAs
- polished hover/button states

The color palette should feel like serious productivity software.

5. Improve visual rhythm
Avoid every section looking like the same grid of white cards.

Mix section types:
- split hero
- before/after comparison
- large product proof section
- workflow timeline
- privacy/delivery diagram
- pricing cards
- FAQ accordion
- download trust panel

Keep the page easy to scan, but make it visually more interesting.

6. Upgrade the Featured Product section
Make QuickShotTransfer feel like the flagship first product.

Include:
- “Featured Product” or “First product”
- QuickShotTransfer name
- product mockup
- concise benefit copy
- Free plan badge
- CTA buttons: “Download for Windows” and “View product”
- feature highlights:
  - Secure QR pairing
  - Browser-based phone upload
  - Recent image inbox
  - Copy, preview, open folder actions

This section should feel important, not like a normal card.

7. Improve the “How it works” section
Make it more visual and less text-heavy.

Use a clean 4-step flow:
1. Install the Windows app
2. Scan the QR code
3. Send images from your phone
4. Use them on your PC

Use icons, mini screenshots, or connected step cards.

8. Improve the objection/comparison section
Create a polished section:
“Why not just use email, iCloud, or Phone Link?”

Make it a compact comparison:
- Email: clutters inbox and adds steps
- Cloud folders: good for libraries, slow for quick handoffs
- Phone Link: broad phone connection, not focused visual capture
- QuickShotTransfer: built for fast iPhone-to-PC image handoff

Make QuickShotTransfer visually stand out.

9. Improve the privacy/trust section
Make this section more polished and reassuring.

Use a simple diagram:
Phone → QuickShot Cloud → Paired Windows PC

Copy:
“Images are temporarily processed through QuickShot Cloud to deliver them to your paired Windows PC.”

Add trust cards:
- Secure pairing
- Temporary processing
- Local desktop saving
- Image-only uploads

Do not imply permanent cloud storage.

10. Improve pricing visual hierarchy
Pricing should clearly show:
Free:
- $0
- 30 images/month
- 5 MB max per image
- No credit card required

Pro:
- $6.99/month
- $59.99/year
- Save 28%
- About $5/mo billed yearly
- images up to 50 MB
- higher monthly usage

Make Pro visually recommended, especially yearly, but do not hide monthly.

Add a small mini FAQ below pricing:
- Is Free really free?
- What happens if I hit the Free limit?
- Can I cancel anytime?
- Is this permanent cloud storage?

11. Improve the Download page
Make the Download page feel trustworthy and action-focused.

Add:
- big “Download for Windows” CTA
- Windows 10/11 compatible
- Free plan available
- No credit card required
- simple setup timeline:
  Download → Sign in → Scan QR → Send first image
- trust note about secure paired upload

Do not make the Download page too long.

12. Improve the Support / FAQ page
Make it organized and polished.

Use categorized FAQ accordions:
- Setup
- Images and limits
- Billing
- Privacy
- Troubleshooting

Add a “Still need help?” card, but do not use fake placeholder email. Use a neutral placeholder like:
“Support contact coming soon” or a configurable support email field.

13. Mobile responsive design
Make sure mobile layouts feel intentional:
- hero stacks cleanly
- product mockups resize well
- pricing cards are readable
- FAQ accordions are easy to tap
- CTAs remain visible and clear

14. Keep copy accurate
Use:
- “images” broadly
- “screenshots, photos, and visual references” in marketing copy
- “No iPhone app required”
- “browser upload page”
- “Windows PC”

Avoid:
- “photo backup”
- “permanent cloud storage”
- “native iPhone app”
- “AI/OCR/search” as current features
- fake roadmap promises

15. Final design quality target
The result should feel:
- serious
- premium
- credible
- launch-ready
- not generic
- not overdesigned
- not playful
- not like a rough prototype

Think: a polished paid software utility website that someone would trust enough to download a Windows app and pay for Pro.
